历史安装、状态恢复、诊断、相邻版本操作、技能分层和规格同步已在对应范围验收。原检查中的失败、补验及合成批准保留在证据中，不以最新通过覆盖。

- 技能优化的部分完整轮曾失败，后续定向补验分别记录；只有需求关联和规格同步的当时完整CI分别为315/315、344/344，不能将其他轮补验拼成一次全绿。
- 已验收的单任务链包含真实测试、独立审查、合成批准和中断恢复；合成批准不是真实业务验收。未来任务的旧增量基准仍需更新与重新确认。
- 旧EOF、限流及重连失败保留。旧模型复验已按用户决定跳过；其他平台、任意历史迁移、强隔离、生产和框架远端CI仍未完整验证。

工具检查本地记录与文件一致性，不认证人类验收、真实检查执行或审查身份。

## 运行检查

`npm run ci` 运行76份必测、构建与打包，原事件和汇总写入 `.artifacts/`。真实模型评测有成本，需另外指定完整包、客户端和仓库外新目录：

```text
node tests/end-to-end/usability-run.mjs --out <新目录> --package <完整包> --cli <实际CLI>
```

`--resume` 只复算或接续已完整落盘的会话。部分会话和业务文件变化会保留证据并拒绝复用，不自动重复模型。当前超预算案例会使驱动退出非零，这是实际结果。
