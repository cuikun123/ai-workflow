`runtime/`检查运行时，`codex-client/`与`end-to-end/`保存客户端判定/驱动及回归，各方法目录检查技能契约，`helpers/`和`fixtures/`提供必要辅助及固定旧包。这些属于框架开发资料，不装进业务项目；虚构输入不当真实需求或批准。

`node tests/end-to-end/optimization-run.mjs --out <dir> --package <dev10解包目录> --cli <实际CLI>`

`node tests/end-to-end/optimization-chain.mjs --out <dir> --package <dev10解包目录> --cli <实际CLI>`
