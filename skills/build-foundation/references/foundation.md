# 建立最小可用工程的方法

方案已明确，需要真实连通与基础约定时读取。共同判断依[工作契约](common/work-contract.md)，接手/写入/工具条件依[写入契约](common/write-contract.md)。需要专项方法先按[能力表](common/capabilities.json)找到真实提供者；以下能力ID不是原生Skill名称，固定依赖缺失不能用基本方法掩盖。

## 前置与主责

读取项目 AGENTS、已有导航、overview、当前 scope/design/tasks/verification，以及 foundation 的 engineering、experience、security、quality、operations 和相关规格；核对实际工程与工具。业务模板不是已确认需求，空文件不要求全部填满，接入成功不代表地基完成。

目标或关键方案未明确时，利用已有资料补查；按需由 clarify 整理用户目标、开源候选、技术偏好、范围及验收，再由 planning 安排成果。已有具体范围、方案、计划与实施授权不重复确认。当前成果已提交待验收则停在原验收点，不因“补地基”绕过。

由 implementation 调用时，本项只是当前任务的方法，不再启动 implementation。独立调用时，当前主 Agent 承担同样责任：确认当前成果，实施、验证、组织独立审查与有效问题修复复查，提交用户验收并等待；通过后仅收尾已交付部分，再判断下一步。缺少独立审查工具如实保留，不能把自查或分角色自述当独立审查。

## 建立并实际验证

1. **保留已有工程。** 找到真实启动、配置、依赖、测试及数据入口，复用适用约定。只固定会让组件各自实现后不兼容的接口、依赖方向和数据归属；不为凑技术栈增加数据库、前端框架、服务或付费资源。新依赖先核对具体来源、版本、许可、运行条件及写入行为。
2. **做最小完整链路。** 按确认范围让必要组件真实连通：例如客户端至接口、接口至存储。没有其中某组件需求时不强加。配置说明区分示例和真实值；敏感信息不写文档、日志或提交产物。启动服务、创建数据及环境变更分别核对授权和输出位置。
3. **验证实际行为。** 用项目命令启动并检查必要健康状态、最小读写、关键错误路径；存在持久化要求时关闭并重启后核对数据。测试替身不能替代目标要求的真实连通。检查进程、端口、测试数据及日志的归属与收尾；数据清理仍按已有授权，不删除用户资料。
4. **形成可复用约定。** engineering 记启动/构建/检查和组件边界；experience 记必要体验规则；security 记输入、权限、敏感信息与数据保护；quality 记 DoD 和必要检查；operations 记健康观察、日志、配置、数据位置及恢复条件。只写已确认且本轮授权落实的约定；未定内容留在设计，不能提前冒充生效规则。

## 交付与记录

主 Agent 按当前成果授权修改工程、测试与约定，进度和必要证据只归 tasks/verification；没有适用迭代不自行初始化，先交接缺项。写入与历史保护按[写入契约](common/write-contract.md)，不写 state.yaml，不引入上游 memlog、票据树或状态运行时。工程地基同样遵守任务Git生命周期：起步前由原主Agent读取实际可用implementation完整方法，核对已有改动、同步基线、任务分支/worktree，完成提交版本的必要检查与独立审查后创建PR交用户验收；明确通过才收尾、最终检查、Squash及清理。独立调用由当前主Agent承担同样责任，不递归启动第二套执行流程；缺方法/工具就返回条件，不能跳过Git前置。

新个人项目的建议默认配置为GitHub私有仓库、origin/main；已有项目保持实际配置。默认配置不授权创建远端、初始化仓库、配置作者或更改可见性，需按具体项目请求核对。依赖、配置、端口、数据和进程须在任务目录按实际授权准备，worktree不自动复制被忽略资料或隔离运行资源；保存与清理时保留必要配置、证据和用户数据。

按真实风险复用 testing 的检查、diagnosis 的调查、review 的独立审查方法；先读已可用能力完整说明。共用同一份要求、目标内容/版本、授权与证据，返回当前主流程，不重复运行仍适用的检查或启动第二套审查。能力缺失不伪称调用，也不临时安装上游。

交付给出工程位置、已核对的启动与检查命令、最小操作及预期、真实运行证据、未验证项、独立审查结果与用户验收状态。只有目录和配置没有运行证据时称“骨架已建，运行未验证”；地基验收与业务迭代验收分别处理。

例如已确认“本地 HTTP 加文件存储”时，启动真实回环服务，写入、读取、关闭并重启核对持久化，同时验证非法输入；不能用返回固定 JSON 的健康检查代替存储连通，也不能自行换成云数据库。
