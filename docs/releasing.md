# 安装包与支持范围

当前为 **0.3.0-dev.12 内部候选版**，技能资源为 **0.3.3**。用户包隔离与只读上下文已验收，本次任务绑定候选尚待验收，未公开发布。同版本候选用准确来源摘要区分，版本号不代表所有后续功能已经实现。

## 分清三种目录

| 你拿到的内容 | 怎样使用 |
| --- | --- |
| 完整工具包或 tgz 解出的 `package/` | 在该目录运行 `node bin/iterlane.mjs` |
| 试用 ZIP | 解压后运行 `node runtime/bin/iterlane.mjs`，另带收藏示例 |
| 已安装的业务项目 | 在项目根目录运行 `node .ai-workflow/bin/iterlane.mjs` |

运行包包括工具、十一项技能、必要资源、用户教程与许可；框架维护设计、交接、内部验证记录和维护者规则不随安装。先读[快速开始](quickstart.md)，安装后的开发过程见[使用指南](usage.md)，参数见[命令参考](../scripts/README.md)。

包外的 `delivery.json` 和 `SHA256SUMS` 标识试用ZIP，运行包内的 `resource-manifest.json` 标识资源，项目内的 `.ai-workflow/manifest.json` 标识实际安装。摘要用于校验一致性，不是来源签名。

## 支持范围

当前主要用于Windows本地新项目；既有验证环境为Windows 11 x64、本地NTFS、PowerShell 5.1、Node.js 24.18.0和Codex CLI 0.169.0。Node要求为 `>=24.18.0 <25`。安装、工具检查、一次真实客户端调用和业务验收分别判断。

本候选提供只读 `context inspect/guard`、地基变化诊断，以及当前任务 `context bind`、v3任务声明修订和启动/恢复/验收/收尾时的绑定核验；C3已完成实现与必要检查，成果待用户验收。Claude Code和Pi自动接入尚未提供。`doctor --client` 当前仍只使用已有Codex接入，不能用于证明其他客户端可用。

其他平台、旧业务项目接管、任意历史迁移、强隔离和生产部署未获完整验证。新初始化项目的状态依据包含地基；旧书签未跟踪时明确显示untracked，不自动重写旧进度。原文、目录或资源无法可靠读取时上下文guard返回unknown并退出非零。

## 版本操作与已知限制

项目固定安装版本，由用户主动触发明确支持的升级。此候选尚未提供dev.11到dev.12的升级或回滚路径；已有项目保留现有安装，不要用新包的init覆盖。既有dev.5/dev.6固定路径使用其匹配工具，不能混用本候选。

普通本地检查核对资源、引用和状态的一致性，不认证批准来源、独立审查身份或检查是否真实执行。自动化通过也不替代用户验收。真实模型连接取决于客户端自身账户和服务；框架不保证连接稳定或所有配置可用。

尚无长期安全维护承诺。敏感问题按[安全反馈](../SECURITY.md)私密报告，先脱敏日志。
