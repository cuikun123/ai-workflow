# 安装包与发布状态

Iterlane 目前是内部试用工具，尚未在 npm 或 GitHub Release 公开发布。安装包中的完整版本号用于区分文件与兼容性；预发布版本不代表长期维护承诺。

## 如何区分安装包

| 用途 | 完整版本 | 内容 |
| --- | --- | --- |
| 当前试用包 | `0.3.0-dev.10` | 运行工具、十一项技能、公共参考、模板、数据结构和许可 |
| 旧版安装示例 | `0.3.0-dev.6` | [快速开始](quickstart.md)所用的固定交付 ZIP、工具包和收藏示例 |

快速开始中的文件名、版本和校验值对应同一个旧版安装示例。不能替换为其他安装包的数据，也不能据此将旧项目直接升级到当前试用包。获取文件及核对摘要的方法见[验证记录](../tests/README.md)。

包内的资源清单、依赖清单和许可随构建提供。文件摘要用于检查一致性，不是来源签名。支持环境与恢复限制见[快速开始](quickstart.md)。

## 准备后续发布

1. 确定支持范围、版本、兼容性和已知限制。
2. 从固定源码和锁定依赖构建，检查资源、许可和产物摘要。
3. 完成适用测试、独立审查与用户验收，保存实际结果。
4. 在获得对应仓库和发布平台授权后，执行发布并核对结果。

旧固定包保持原版本和原摘要，不用文档更新替换已验证产物。升级仅适用于明确支持的路径，其他历史迁移需要单独验证。

详细证据见[验证记录](../tests/README.md)。维护方法见[贡献说明](../CONTRIBUTING.md)，安全反馈见[安全说明](../SECURITY.md)。
