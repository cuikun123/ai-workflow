# 版本与支持范围

当前版本是 **0.3.0-dev.12**，技能版本 **0.3.3**。这是内部试用版，还没有公开发布。

## 分清三种目录

| 你手里的是 | 在哪里运行命令 | 命令写法 |
| --- | --- | --- |
| 试用 ZIP 解压后的目录 | 解压目录 | `node runtime/bin/iterlane.mjs` |
| 完整工具包（或 tgz 解出的 `package/`） | 工具包目录 | `node bin/iterlane.mjs` |
| 已安装的项目 | 项目根目录 | `node .ai-workflow/bin/iterlane.mjs` |

安装包里有工具、十一项技能、项目模板、使用文档和许可文件。框架自己的设计、交接和测试记录不会装进你的项目。

几个用来核对完整性的文件：

| 文件 | 位置 | 作用 |
| --- | --- | --- |
| `delivery.json`、`SHA256SUMS` | ZIP 所在的交付目录 | 核对 ZIP 本身 |
| `resource-manifest.json` | 工具包内 | 核对工具包里的文件 |
| `.ai-workflow/manifest.json` | 项目内 | 记录这个项目实际装了什么 |

这些摘要只能证明文件没被改动，不能证明文件来自谁。

## 已经支持

- 在 Windows 上安装到全新的空项目，并检查安装结果。
- 管理任务状态，中断后恢复。
- 读取最新的项目约定，并在每个任务开始、检查、交付时核对。
- 验收后同步规格。
- 诊断本地安装问题，并按记录恢复。

验证环境：Windows 11 x64、本地 NTFS 磁盘、PowerShell 5.1、Node.js 24.18.0、Codex CLI 0.169.0。Node.js 版本要求为 `>=24.18.0 <25`。

## 还不支持

- **把框架接入已有代码的项目。** 目前只支持全新的空项目。
- **其他系统和其他 AI 工具。** Claude Code 和 Pi 的自动接入还没做。`doctor --client` 只能检查 Codex。
- **从 dev.11 升级到 dev.12，或回退。** 已经装了旧版本的项目，保持原样，不要用新包的 `init` 覆盖。
- **生产部署。** 框架不会替你部署。部署需要你的项目自己的工具和授权。
- **自动拦截客户端原生工具。** 共享判定、命令行和完整包接口可供适配者使用，但 Codex、Pi、Claude Code 的原生工具仍需各自适配和验证。
- **完整 Git 执行范围。** 共享 Git 判定只覆盖已识别的本地操作；主分支集成还需要受控宿主提供当前 PR 观察。缺少平台观察时不放行集成。

早期装过 dev.5 的项目，仍可以用固定的 dev.6 工具包升级到 dev.6，或从 dev.6 回退。这条路径要用 dev.6 工具包，不能用本版本的工具。新用户不涉及这一条。

## 检查能证明什么

- **能证明**：文件、记录和状态彼此一致，没有缺失或被意外改动。
- **不能证明**：确认真的来自你、审查真的是独立做的、检查真的运行过、成果在业务上正确。这些靠 AI 如实记录和你亲自验收。

AI 工具能否连上模型，取决于工具自己的账号和网络，框架不保证。

## 工具操作判定的边界

受控宿主须把最终执行函数使用的实际参数交给共享门槛，并只在当次检查允许时执行。源码中的判定接口用于适配开发；客户端接入范围仍以本页为准。

- 单个请求的 UTF-8 JSON 上限为 16 MiB，每项文件全文上限为 8 MiB。
- 普通 Markdown 正文可按全文上限检查；迭代中的范围、设计、任务和验证文档沿原协议保留 1 MiB 上限。超出后返回未知，不放行操作。
- 符号链接、硬链接写目标及路径别名不在允许范围。
- 门槛根据宿主实际发现的可执行文件身份识别已知 Git 和解释器。任意 shell、未覆盖的操作与参数不能借工程命令声明放行。
- 工程命令还须匹配下表中的实际工具身份。其他二进制程序返回未知；把程序写入任务声明不能证明它属于工程命令。
- 已确认工程命令内部的文件、网络或间接 Git 行为不由这次判定全面控制。
- 文件和 Git 观察不是操作系统的原子快照。多文件执行与外部编辑仍需宿主在执行前重查，并处理实际执行失败。

判定接口不认证批准来源、检查实际执行或审查独立性，也不提供操作系统隔离。

维护者可用下表确定默认能够核对的工程工具。工具必须由宿主实际发现，文件摘要须匹配；每次执行还需对应的任务范围和完整参数确认。

| 工具 | 核对来源 |
| --- | --- |
| Node.js | 运行共享内核的当前 Node 程序 |
| Go | 宿主发现的 go 程序 |
| Rust | 宿主发现的 cargo、rustc 程序 |
| Java、.NET | 宿主发现的 java、javac、dotnet 程序 |
| CMake、Ninja | 宿主发现的同名程序 |
| GCC、Clang | 宿主发现的 C 或 C++ 编译器 |
| Visual C++、MSBuild | 宿主发现的 cl、msbuild 程序 |
| Windows 文件查找 | 宿主发现的 where 程序 |
