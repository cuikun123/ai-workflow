# 结构定义目录

约定供程序读取的数据有哪些字段、类型与允许值，例如工作状态、未来配置和子 Agent 结果。目前未实现正式 schema 或校验器。

优先明确 state.yaml；有实际配置或结果格式后再建立相应结构定义，不为了填满目录预先制造格式。

结构定义约束表达，不限制框架能做哪些事情。新能力需要新字段时，应同步设计读取逻辑、兼容和迁移。

格式正确不能证明结果真实。业务文档主要使用 Markdown，不能把所有自然语言内容都塞进结构校验。

候选状态模板位于 [业务项目模板](../templates/project/docs/workflow/state.yaml)。这份草案不是本框架仓库的运行状态。
