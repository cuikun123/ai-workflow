# Iterlane（迭序）

Iterlane 让 AI 编码工具按一套固定流程开发你的项目。

- **你**：说明想要什么，确认方案，亲自验收成果。
- **AI**：调查、设计、写代码、跑检查，并把项目资料记下来。

每完成一件事，项目里都留有记录：做了什么、检查过什么、你是否验收、下一步是什么。换会话或换模型后，AI 读这些记录就能接着做。

## 一次开发的样子

以一个收藏网页的小应用为例：

1. **你说目标**：“我想保存网页标题和地址，刷新后还在。”
2. **一起定方案**：AI 问清关键问题，给出方案和任务。你确认后它才开始做。
3. **AI 实施并检查**：写代码，运行测试，做必要的审查，发现问题自己修。
4. **你验收**：AI 给你体验入口和操作步骤。你试过后说“通过”，或者指出问题。
5. **AI 收尾**：更新项目资料，再接着做下一件事。

新项目的第一轮叫“项目地基”：先搭一个能运行的最小工程，定下基本约定，再开始做业务功能。

## 适用范围

目前是内部试用版。主要在 Windows、Node.js 24 和 Codex CLI 上验证过，适合从零开始的新项目。哪些情况已经支持、哪些还不支持，见[版本与支持范围](docs/releasing.md)。
