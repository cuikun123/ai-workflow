# Iterlane（迭序）

Iterlane 是面向 AI 编码的项目工作流，把需求、实施、检查、用户验收和规格更新连起来。简单的小改动直接处理，需要设计和验证的工作再展开相应方法。

## 能帮你做什么

- 澄清需求和方案，将工作拆成可验收的任务。
- 按需读取技能说明，减少小任务的额外步骤。
- 检查需求、场景、任务和验证记录能否对应。
- 等待用户验收，只把已通过的任务更新到当前规格。
- 查询进度、暂停和恢复；发现文件冲突时保留现场。

框架包含十一项技能，以及安装、检查、诊断和恢复工具。业务判断由 AI 完成，Git 和部署操作需要项目自身的工具与授权。

## 怎么使用

1. 按[快速开始](docs/quickstart.md)将工具包安装到明确的新项目。
2. 在 codeg 打开项目根目录，创建新会话，直接说明需求。
3. 确认方案并逐任务验收；也可以直接要求查询、暂停或恢复。

想先看应用效果，可以运行[收藏示例](examples/bookmarks/README.md)。源码维护方法见[贡献说明](CONTRIBUTING.md)，技能选择见[能力索引](skills/README.md)。

## 适用范围

当前用于内部试用，尚未公开发布。已验证的环境是 Windows 本地新项目、Node.js 24、Codex CLI 和所选 codeg 入口；具体安装版本与限制见[发布说明](docs/releasing.md)和[快速开始](docs/quickstart.md)。

旧项目接管、更多平台和生产部署仍需另外验证。框架检查本地文件与记录的一致性，不认证人类身份，也不保证模型服务稳定。
